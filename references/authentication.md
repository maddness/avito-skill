# Первый вход и повторное подключение

## Обычный запуск на компьютере пользователя

```text
CLI auth login
CLI session status
```

Нужны Node.js 22+ и установленный Chrome/Chromium. Помощник находит браузер, открывает видимое окно с отдельным постоянным профилем и возвращает `ui_url` страницы подключения. Покажи эту ссылку пользователю. Если Chrome не найден, укажи путь через `--browser-path FILE`.

Пользователь вводит логин, пароль и SMS-код непосредственно на Авито и сам решает капчу. Помощник не заполняет эти значения, не снимает изображения формы, не возвращает текст страницы и не записывает сетевые тела авторизации. Наблюдения ограничены состояниями `credentials`, `sms`, `captcha`, `video`, `profile`, `ready` и техническими состояниями ожидания/ошибки.

Вступительные экраны видеопроверки помощник проходит только при однозначной кнопке и повторной проверке текущего экрана. Согласия остаются пользователю. Если Авито показывает ссылку на телефон, страница подключения выводит кнопку её открытия. Ссылка остаётся в памяти процесса и доступна пользователю на приватной странице; в stdout и auth-status.json попадает только признак её наличия. Если автоматическое извлечение не сработало, пользователь может вставить выданную Авито ссылку в запасное поле страницы подключения. Принимаются только HTTPS-ссылки домена Avito и его поддоменов; сторонний провайдер проверки требует отдельной интеграции.

Исходную вкладку сохраняй открытой. Успех на телефоне не заменяет проверку исходного браузера: помощник ждёт чистого от auth challenge экрана, определяет текущий профиль, извлекает применимые к web API cookie и отдельно проверяет HTTP-доступ. Только после этого атомарно заменяет session.json. При нескольких профилях пользователь выбирает нужный; переключение выполняется в самом Авито.

## Принудительная проверка нового входа

```text
CLI auth login --force-login true
```

Помощник сначала показывает «Готово к повторному входу» и ждёт, пока пользователь сам выйдет из Авито. Старый вход не сбрасывается автоматически. Новый успех принимается только после наблюдённого гостевого HTTP-статуса и последующего завершённого входа. Обычный запуск без этого флага может повторно использовать уже авторизованную сессию.

## Хранение и переменная окружения

Сессия сохраняется в стандартном приватном state, см. setup.md. Для выбора файла поддерживается `AVITO_SESSION_FILE` с **абсолютным путём**:

```bash
export AVITO_SESSION_FILE="$HOME/.local/state/avito/session.json"
```

Переменная содержит путь, секрет находится в файле 0600. При стандартном пути export не требуется: последующие команды находят файл автоматически. В env не нужно копировать строку cookie или пароль.

Если state уже связан с профилем, вход в другой профиль не заменит его сессию. Для другого профиля используй отдельные state и session file. Повторный импорт сохраняет binding и журнал операций.

## Явное подключение браузера на удалённой машине

Сам скилл не предоставляет удалённый рабочий стол. Нужен уже настроенный приватный доступ пользователя к браузеру. Например, на тестовой VM такой доступ предоставлял BB; в другом хосте его обеспечивает выбранная инфраструктура.

```text
CLI auth login --cdp-url http://127.0.0.1:CDP_PORT --page-id TARGET_ID
```

Используй только endpoint и вкладку, явно выбранные владельцем. Вкладка должна находиться на `https://www.avito.ru`. CDP принимается только на loopback и не публикуется в сеть. Подключение не закрывает браузер, не очищает cookie и не запускает ещё один контроллер удалённого экрана. Не собирай cookie чужих сайтов: экспорт ограничен URL Авито внутри выбранной target session.

Чтобы страница подключения открывалась на телефоне, её loopback HTTP-порт можно разместить за **уже аутентифицированным** reverse proxy:

```text
CLI auth login --cdp-url http://127.0.0.1:CDP_PORT --page-id TARGET_ID
  --port AUTH_UI_PORT --public-origin https://PRIVATE_AUTH_ORIGIN
  --viewer-url https://PRIVATE_BROWSER_VIEWER
```

Это одна команда; переносы здесь обозначают продолжение аргументов. `--public-origin` не создаёт proxy и не предоставляет авторизацию самостоятельно. Никогда не размещай этот интерфейс на общедоступном origin: `/api/state` содержит приватную ссылку видеопроверки. По умолчанию сервер слушает только 127.0.0.1. Он проверяет Host, Origin и CSRF, отправляет no-store, блокирует iframe-встраивание и закрывается после завершения.

## Завершение и восстановление

- Кнопка «Закончить позже», Ctrl+C и timeout сохраняют прежний файл, если отмена произошла до атомарной записи. Уже выполненная запись отражается как завершённое подключение.
- Помощник отсоединяет только собственное CDP-соединение. Браузер остаётся открытым; можно продолжить незавершённый шаг.
- `CLI auth status` показывает последний безопасный статус мастера. `CLI session status` проверяет фактический доступ к API.
- `BROWSER_DISCONNECTED` — выбранная вкладка или браузер закрылись. Открой нужную вкладку и повтори подключение с её актуальным ID.
- `BROWSER_DISPLAY_REQUIRED` — у процесса нет графической сессии. Используй локальный desktop или явно подключённый браузер с приватным удалённым доступом.
- `AUTH_TIMEOUT` — время ожидания закончено; это не срок действия ссылки Авито. По умолчанию ожидание 15 минут, `--timeout-seconds` допускает 10–3600 секунд.
- `BUSY` — уже работает другой вход или остался lock после аварии. Сначала проверь работающий помощник; не удаляй lock только по PID или возрасту.

В этой версии нет автоматического обхода капчи/видеопроверки, записи камеры, OAuth refresh token или переноса доверия устройства между компьютерами.

## Что проверено

16 ноября 2026 владелец реально вышел из аккаунта на тестовой VM и вошёл заново по логину/паролю. Мастер зафиксировал гостевое состояние, дождался входа, сохранил сессию и завершился успешно. После завершения отдельные `session status` и `own list` подтвердили доступ через HTTP без CDP. В этом живом прогоне Авито не запросило SMS, капчу или видео. Их обработка и извлечение официальной video-ссылки проверены на синтетических страницах в отдельном Chrome; полный реальный перенос видеопроверки на телефон в новой версии ещё не прошёл приёмку.
