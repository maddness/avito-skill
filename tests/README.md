# Проверки и разработка Avito

Требуется Node.js 22+. Из корня репозитория:

```bash
node scripts/avito.mjs help
node --test tests/*.test.mjs
```

Тесты используют вымышленные сессии и HTTP-ответы, не обращаются к Авито и не требуют аккаунта, Chrome или npm-пакетов. Они проверяют поиск, сообщения, журнал операций, финансовые ограничения, права файлов и обработку входа. GitHub Actions запускает их на Node.js 22 и 24; workflow имеет только чтение репозитория.

## Что подтверждено живыми проверками

- Поиск по городу, две страницы выдачи, чтение карточек и вопросы двум продавцам.
- Публикация шести собственных вещей без доставки, изменение описания, переключение доставки и снятие с публикации.
- Чтение личных сообщений и ответ покупателю.
- Повторный вход по логину/паролю на Linux VM, сохранение сессии и последующие HTTP-запросы.

SMS, капча и ссылка видеопроверки в новой версии помощника проверены на стенде. Реальный вход через эти дополнительные проверки и первый запуск локального Chrome на компьютере пользователя ещё не подтверждены. Удалённый доступ к браузеру предоставляет окружение, сам скилл его не создаёт.

## Перед открытием репозитория

- Лицензия кода и текстовой документации — [MIT](../LICENSE).
- Проверить состав изменений и историю на секреты; приватные сессии, browser profiles, переписка и диагностические снимки в репозиторий не входят.
- Дождаться зелёных проверок GitHub Actions. Успех локального прогона не заменяет CI.

Скилл использует неофициальный web API Авито. При изменении контракта сначала обновляются скрипты и проверки; агент не должен придумывать запросы во время работы.
